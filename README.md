# PaiPrint

Micro-SaaS de presentes 3D pro Dia dos Pais.

## Local

```bash
npm install
cp .env.example .env.local
# edite WhatsApp e PIX
npm run dev
```

- Loja: http://localhost:3000
- Admin: http://localhost:3000/admin (senha: paiprint2026)

## Deploy Vercel

```bash
npx vercel login
npx vercel --prod
```

Production: https://paiprint.vercel.app
